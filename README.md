# ファイル整理アプリ（Python）

指定したフォルダ内のファイルを拡張子ごとに分類し、`Images` / `Documents` などのフォルダへ自動で整理するアプリです。

## 機能

- 拡張子ベースの自動分類
- 同名ファイルの連番リネーム（`_1`, `_2` ...）
- GUI（Tkinter）
- ドライラン（実際には移動しない確認モード）

## 使い方

```bash
python app.py
```

1. 「参照」から整理対象のフォルダを選択
2. 「整理を実行」または「ドライラン」をクリック

## テスト

```bash
python -m unittest discover -s tests -p 'test_*.py'
```
